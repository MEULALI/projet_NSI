Introduction

Quel que soit le domaine, toute application informatique manipulant des données doit faire face à certains défis inhérents à la gestion de données. Un Système de Gestion de Base de Données (SGBD) est un logiciel générique conçu pour gérer ces problèmes ; lorsque les données sont organisées en tables, il est dit relationnel. L’utiliser dans une application se fait au moyen du langage informatique SQL. Ces SGBD permettent en particulier d’organiser, stocker, mettre à jour et interroger des données volumineuses utilisées simultanément par différents programmes ou différents utilisateurs.Ce chapitre présente les principales fonctionnalités des SGBD, en particulier celles permettant de construire et tenir à jour une base de données au moyen de SQL. Le chapitre suivant poursuit avec l’interrogation des données en SQL et l’inclusion de SQL dans un programme en Python, qui permet d’écrire des applications réalistes simples en Python interagissant avec un SGBD.
